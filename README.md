# AtlasRAG

### A Multilingual Retrieval-Augmented Intelligence System for Disaster Knowledge Management

> **Research Status:** 🚧 Research & Planning Phase (Milestones 1–2 Completed)

---

## Overview

AtlasRAG is a research-oriented Retrieval-Augmented Generation (RAG) system designed to improve disaster knowledge management through multilingual semantic search, grounded AI responses, and transparent source citation.

The project aims to bridge the gap between traditional document retrieval systems and modern AI-powered knowledge assistants by enabling users to query disaster-related documents using natural language while ensuring that every generated response is supported by verifiable evidence.

This repository is being developed as a research portfolio project following academic software engineering practices suitable for graduate admissions and open-source collaboration.

---

## Research Objectives

* Develop a multilingual disaster knowledge retrieval system.
* Evaluate modern Retrieval-Augmented Generation techniques.
* Compare lexical, dense, and hybrid retrieval methods.
* Improve explainability through citation-grounded responses.
* Build a reproducible, research-grade AI system.
